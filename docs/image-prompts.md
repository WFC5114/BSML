# BSML mockup: image prompts

Each grey placeholder on the mockup site carries a code (IMG-01, IMG-02 …). Paste the matching prompt into your image generator, then send the picture back (or drop it into `assets/img/` in the repo with the code as the file name, e.g. `IMG-01.jpg`).

**Add this style line to the end of every prompt** so the set looks like one family:

> Style: editorial documentary photography, natural window light, warm but restrained colour, soft film grain, shallow depth of field, calm and premium, real people of mixed ages and backgrounds, no text, no logos, no uniforms, nothing staged or ceremonial. Aspect ratio as noted.

Things to avoid in every image (add as a negative prompt if your tool has one): text, watermarks, logos, robes, candles, rituals, chanting, people bowing, school uniforms, Hogwarts or Harry Potter look, crests on clothing, glowing AI holograms, robots, screens as the focus, stock-photo grins, extra fingers.

Archive images (IMG-05 to IMG-09) should ideally be **real photos from the owner**. Use the prompts only as stand-ins for the mockup, and label them as illustrations, never as real history.

## The history scroll on the home page

The scroll is drawn in code as pen lines, so it needs no pictures to work. If the owner wants a richer version later, the brief in the project map (section 7) asks for a **human illustrator**. To explore the look first, these prompts give reference art in matching styles:

**SCROLL-A · 1925 ink etching** (16:9)
Hand-drawn ink etching of a Boston street in 1925: a row of brownstone houses with bow fronts and stoops, the Custom House clock tower behind, a streetcar on rails, gas lamps, cream paper, fine cross-hatching, no colour.

**SCROLL-B · 1940s sepia wash** (16:9)
The same Boston street in the 1940s drawn in ink with sepia watercolour wash, a steamship in the harbour on the left, travellers with suitcases.

**SCROLL-C · 1960s watercolour** (16:9)
The same street in loose watercolour with first soft colours, the Prudential Tower and the red Citgo sign appearing in the skyline.

**SCROLL-D · 1984 granite church** (16:9)
Warm film-photograph look of a granite Gothic church with a square tower beside an arboretum, trees changing from summer green to autumn orange.

**SCROLL-E · 2026 revival** (16:9)
Night scene, deep navy background, an elegant exploded architectural diagram of a four-storey school building drawn in fine glowing gold lines, each floor separated and floating, minimal, premium, like an Apple product reveal.
